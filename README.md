# hoimod1

Чит-кнопки для Hearts of Iron IV 1.16. Решения видит только страна, которой управляет человек. ИИ их не берёт.

## Как включить

В лаунчере отметьте мод `hoimod1`. Игре нужен файл в каталоге модов с путём к этой папке. На этой машине он создаётся локально и в Git не входит, потому что путь абсолютный.

На другой машине создайте `mod/hoimod1.mod` в каталоге документов Hearts of Iron IV:

```
name="hoimod1"
version="1.0"
tags={
	"Gameplay"
}
supported_version="1.16.*"
path="/полный/путь/к/hoimod1"
```

`descriptor.mod` в репозитории пути не содержит.

## Кнопки

Категория «Чит-кнопки» на вкладке решений.

- **Технологии и прорыв** — один раз. 100 очков прорыва в суше, флоте, авиации и ядерной области, все технологии. Если есть La Résistance и ещё нет агентства, оно создаётся.
- **Нацдух +500%, +1000%, +3000%, +5000%, +7000%, +10000%** — ставит дух этой силы и снимает предыдущий. У каждого также 8 слотов агентов. Бонусы не складываются.
- **Убрать нацдух** — снимает только этот дух. Ресурсы, постройки, людские ресурсы и технологии остаются.
- **Ресурсы** — нефть, алюминий, резина, вольфрам, сталь и хром в каждом контролируемом регионе.
- **Людские ресурсы** — +1 000 000 в запас страны. Каждое нажатие добавляет ещё миллион.
- **Слоты строительства** — +5 в каждом контролируемом регионе.
- **Военные заводы**, **фабрики**, **авиабазы** — +5. Потолки игры: заводы 20, авиабаза 10.
- **Радары** — +1, потолок 6.
- **Узлы снабжения** — в каждой провинции. Повторно провинция узел не получает.
- **Железные дороги** — уровень 5 от столицы к лучшему узлу каждого региона. Нажимать после узлов. Линия не заходит в каждую провинцию: поток идёт в узел региона, остальные узлы раздают снабжение вокруг.
- **Ракетные шахты** — 3 на регион, это потолок.
- **Ядерные реакторы** — один на регион, это потолок. Перед постройкой завершается спецпроект реактора.

## Где менять числа

В [`common/ideas/hoimod_ideas.txt`](common/ideas/hoimod_ideas.txt) `1` — это `+100%`. Кнопки уже переводят проценты сами: `+500%` записано как `5`, `+10000%` как `100`. Туда входят скорость строительства, темпы исследований, скорость спецпроектов, объём заводского производства, производительность верфи, потолок, рост и старт эффективности производства.

Практический потолок скорости — около `1000` (`+100000%`): дальше день уже не делится. Для объёма производства выше `1000`–`10000` склад техники может переполниться и показать отрицательное число.

Количество ресурсов — `@hoimod_resources` в [`common/scripted_effects/hoimod_effects.txt`](common/scripted_effects/hoimod_effects.txt). Сейчас `10000` каждого.

## Технологии

Список всех технологий собран из файлов игры 1.16.10 и лежит в `common/scripted_effects/hoimod_research_all.txt`. Взаимоисключающие ветки тоже открываются, их бонусы складываются.

После обновления игры список можно пересобрать:

```
python3 tools/generate_research_all.py
```
